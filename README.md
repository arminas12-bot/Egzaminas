# Egzaminas

### Išankstinė (papildoma) egzamino užduotis.

### Programa
Ši programa geba tikrinti/analizuoti pateiktus .txt formato failus.
Principas:
1. Nuskaito tekstą iš duoto failo, taip pat sutvarko žodžius - paverčia mažosiomis raidėmis viską.
2. Suskaičiuoja, kiek kartų pasikartoja kiekvienas žodis.
3. Gautus rezultatus surūšiuoja pagal dažnį (o paskui pagal abėcėlę).
4. Sukuria cross-reference tipo lentelę, t.y. parodo, kuriose eilutėse pasikartojo tam tikras žodis.
5. Visus duomenis išveda į tekstini failą (isvesti_zodziai.txt).
6. Papildomai, iš kito pateikto tekstinio failo suranda visas įmanomas nuorodas.
7. Visų pirma, patikrina ar galūnės atitinka pateiktą sarašą, tuomet pašalina pasikartojimus bei galiausiai, surūšiuoja.
8. Visos gautos nuorods yra išvedamos į tekstinį failą (isvestos_nuorodos.txt).
IŠAVDA: programa automatiškai suranda pasikartojančius žodžius ir atlieka jų analizę bei išrenka visas tekste esančias internetines nuorodas.
